# Roadmap

## Current classroom version

- [x] Publish an A2A Agent Card from a configurable student profile.
- [x] Register with the instructor registry using A2A.
- [x] Refresh the directory and send A2A questions to registered peers.
- [x] Track outgoing task status and retrieve approved replies.
- [x] Create an individual incoming task for each question.
- [x] Let the student edit, approve, or decline each proposed answer.
- [x] Provide Agent Chat and the four course workflow tabs.
- [x] Add a Codespaces development container and unit tests.

## Later improvements

- Persist tasks across app restarts.
- Add authenticated sender identity and abuse controls before use beyond the course exercise.
- Add streaming updates and retry/idempotency handling.
- Migrate the classroom wire subset to the maintained A2A SDK when the instructor registry supports the same protocol version.
- Add an experiment report comparing direct peer messaging with registry-mediated discovery.
